# Backend — Rossmann Forecasting API

FastAPI service that serves sales forecasts using the backtest-selected
model (seasonal-naive, SARIMA, Prophet, or pooled LSTM) per store, read from
`models/model_registry.json`.

## Run locally

From the **project root** (not from inside `backend/`):
```bash
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload
```
Visit `http://127.0.0.1:8000/docs` for interactive API docs.

Requires `models/model_registry.json` and the trained model files it
references (`.pkl` / `.keras`) to already exist — generated by running
notebooks `03`, `04`, and `05` first.

## Environment variables

Create a `.env` file in the project root (see `../.env.example`):
```
DATABASE_URL=postgresql://postgres.<project-ref>:<password>@aws-0-<region>.pooler.supabase.com:5432/postgres
```
Falls back to local SQLite if unset — fine for local testing, but the
deployed backend needs a reachable database (Supabase), since a local
SQLite file won't exist on the hosting platform.

## Deploying to Render

1. Push this repository to GitHub (make sure `models/*.pkl`, `models/*.keras`,
   and `models/model_registry.json` are actually committed — they're small
   enough to check in and the deployed backend needs them).
2. In Render: **New → Web Service** → connect this GitHub repo.
3. Configure:
   - **Root Directory:** leave blank (repo root) — the Dockerfile needs
     access to the sibling `src/` and `models/` folders, not just `backend/`.
   - **Dockerfile Path:** `backend/Dockerfile`
   - **Docker Build Context Directory:** `.` (repo root — this is the default)
4. Add environment variable: `DATABASE_URL` = your Supabase connection string.
5. Deploy. Render sets `$PORT` automatically — the Dockerfile's `CMD` already
   respects it.
6. Once live, note the public URL (e.g. `https://rossmann-backend.onrender.com`)
   — the Streamlit frontend needs this as its `API_BASE_URL` environment variable.

## Building/running the Docker image locally (optional, to test before deploying)

From the **project root**:
```bash
docker build -f backend/Dockerfile -t rossmann-backend .
docker run -p 8000:8000 --env-file .env rossmann-backend
```

## Endpoints
- `GET /health` — DB connectivity + registry status
- `GET /models` — every store with a trained model, its selected model type, backtest MAPE
- `GET /history?store_id=&days=` — recent actual sales for a store
- `GET /forecast?store_id=&horizon=&model=` — forecast (`model` optional, overrides the backtest-selected default)
